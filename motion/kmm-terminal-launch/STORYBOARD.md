# Storyboard — KMM Terminal, lancement iPhone

Theme: 094 Match Cut · Format: 1080x1920 (écrans iPhone 15 Pro capturés en 1179x2556) · Length: 20 s · Sound: musique + SFX

## Message & tone
- **Sentence:** I want to say "Ton terminal et ta formation, enfin dans ta poche" in a bold then premium tone, so the viewer feels that everything is finally in one place.
- **Tone arc:** bold → premium → trustworthy → warm
- accent: or KMM #e8c468
- **Motif:** le cercle doré revient trois fois au même endroit de l'écran et change de sens à chaque fois : point du prix → anneau de progression → point final du slogan.

## The seven questions
1. **Le message et le ton** : la phrase ci-dessus. Attaque franche sur deux mots, puis on ralentit pour laisser voir le vrai produit.
2. **Ce qui se répète** : seulement le cercle doré, en motif (3 apparitions, trois sens).
3. **Ce que veut dire chaque transition** : coupe sèche = deux mondes séparés ; iris depuis le cercle = on entre dans l'appli ; le point de tap = le geste de l'utilisateur ; raccord de forme = même place, nouvel espace ; accélération = on bascule ; couleur or = la promesse tenue.
4. **Les couleurs dans le temps** : fond encre partout ; cyan et rouge seulement dans le terminal ; l'or ne domine que deux plans (plan 2 et le slogan final), c'est l'événement couleur du film.
5. **Le composant nouveau** : le téléphone-pièce (coin-flip-phone).
6. **La surprise** : l'iris qui s'ouvre sur un iPhone de profil (1,8 s), puis l'arrêt sur image et la pièce qui tourne (15,5 s).
7. **Une répétition d'un film précédent** : aucun historique, c'est le premier film.

## Frames

### Frame 1 · Hook (0–1,8 s)
- key visual : macro plein écran sur le vrai terminal (heatmap, prix GC) ; le point du prix est entouré du cercle doré. Coupe sèche : macro sur l'anneau de progression de la formation, le cercle doré au même endroit.
- moves first : le mot claque au centre (expo.out), puis le second mot monte (power4.out).
- on-screen words : « Ton terminal. » puis « Ta formation. »

### Frame 2 · Reveal (1,8–8 s)
- key visual : l'anneau s'ouvre en iris sur l'iPhone 15 Pro vu de profil, qui pivote de face et flotte légèrement incliné. À l'écran, la vraie capture du terminal tourne ; une carte signal (ex. SWEEP, score) sort en relief de l'écran.
- moves first : la rotation du téléphone (power3.inOut), puis la carte.
- on-screen words : « Lis le marché. » · « Données d'exemple » en petit.

### Frame 3 · Proof moment (8–15,5 s)
- key visual : le point de tap doré glisse jusqu'à « ⇄ Espace », tape ; l'écran « Où veux-tu aller ? » apparaît ; deuxième tap sur Formation ; l'accueil Formation se construit, l'anneau monte à 64 %, la série et la prochaine leçon arrivent.
- moves first : le point de tap, puis les cartes en cascade.
- on-screen words : « Apprends. »

### Frame 4 · Surprise (15,5–17 s)
- key visual : arrêt sur image d'une demi-seconde, silence, puis l'iPhone tourne sur lui-même comme une pièce : terminal sur une face, formation sur l'autre. Il retombe de face.
- new component : coin-flip-phone. Verbe : réunir. Métaphore : les deux faces d'une même pièce. Vérité : c'est bien la même appli.

### Frame 5 · CTA (17–20 s)
- key visual : l'iPhone recule, le slogan s'empile en Inter Display ; le cercle doré se pose et devient le point final de « poche. ». Logo KMM officiel dessous.
- on-screen words : « Ton terminal. Ta formation. Enfin dans ta poche. » + logo + ligne d'action (App Store ou site, à confirmer).
